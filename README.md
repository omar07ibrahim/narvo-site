# narvo.ae

The NARVO website — static, bilingual (Arabic / English), no build step.

- `index.html`, `assets/` — the site; `assets/media.js` lists the films (generated by `build-media.mjs` in the backup repo).
- `media/` — the films (1080p H.264, faststart) and their posters.
- `vendor/` — the ElevenLabs client SDK (MIT), loaded only when a visitor starts a conversation.
- The hero ribbon is drawn in WebGL (`sheet()` in `assets/site.js`), with a 2D hairline fallback.

## The voice concierge

ElevenLabs agent `agent_8801m50tmrb1fngt81fay6c5xmr1`.

1. The visitor picks Arabic or English, then talks to the agent.
2. The agent asks about the organisation and the need, matches a NARVO solution and agrees a next step.
3. It recaps the conversation, takes corrections, then collects the visitor's name, organisation, role and (optionally) email.
4. It calls the client tool `submit_request`. The site turns the result into a first-person WhatsApp message and shows a green "Send on WhatsApp" button.
5. After the agent's goodbye, WhatsApp opens by itself. The visitor only presses send, and the message reaches the NARVO WhatsApp number (`WA_NUMBER` in `assets/site.js`).

Every conversation is also recorded in ElevenLabs (with data collection fields for the lead).

The "Prefer to write?" form opens the same WhatsApp message.

Open `/?debug` to expose the live conversation as `window.NARVO_DEBUG` for rehearsals.
